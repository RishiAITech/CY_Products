# CY Products - Premium Footwear E-commerce

A full-stack MERN (MongoDB, Express, React, Node.js) e-commerce platform designed for a footwear manufacturer.

## 🚀 Features
- **User Authentication:** Secure Login/Signup using JWT.
- **Admin Dashboard:** Manage products, categories, and orders.
- **Product Management:** Add, update, and delete footwear with image uploads (Base64).
- **Filters:** Filter products by Gender (Men/Women/Kids) and Categories (Safety, Formal, etc.).
- **Payment Integration:** Razorpay payment gateway.
- **Responsive Design:** Fully mobile-friendly UI using Tailwind CSS.

## 🛠️ Tech Stack
- **Frontend:** React, Vite, Redux Toolkit, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas
- **Payment:** Razorpay

## ⚙️ Installation
1. Clone the repo: `git clone https://github.com/your-username/cy-products.git`
2. Install dependencies: `npm install` (in both frontend and backend)
3. Set up `.env` variables.
4. Run frontend: `npm run dev`
5. Run backend: `npm run dev`
